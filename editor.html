🎵 Фондық музыка

Музыка құрылғының ішінде жасалады, сондықтан авторлық құқық мәселесі жоқ. Экспортта таңдалған музыка видеоға қосылады.

💬 Қазақша субтитр

Өшірулі

Маңызды: Web Speech API микрофон арқылы тыңдайды. Сондықтан видеоны дыбыс шығарғышпен (динамикпен) ойнатыңыз немесе өзіңіз қазақша сөйлеңіз. Chrome (Android / компьютер) ең жақсы жұмыс істейді; кейбір браузерлерде (мысалы, iPhone Safari) қазақ тілі қолдау таппауы мүмкін — онда қолмен жазуды қолданыңыз.

🔤 Субтитр қарібі

Үш қаріп те қазақ әріптерін (ә, ғ, қ, ң, ө, ұ, ү, і) көрсетуі керек. Қаріпте әріп жетіспесе, қолданба автоматты түрде резерв қаріпті алады да, жоғарыда ескертеді.
